# 01. 확장 프로그램 기반 자동화

**상태:** 미착수

## 목적

Chrome 확장 프로그램의 최소 동작 경로를 만든다. 사용자가 Side Panel에서 조건을 설정하고 모의 예약 페이지에서 감시를 시작하면, 일치하는 시간 슬롯이 DOM에 추가됐을 때 한 번만 클릭하고 결과 상태를 표시해야 한다.

## 마일스톤

| 마일스톤 | 목표 | 상태 |
| --- | --- | --- |
| M0. 확장 프로그램 골격 | Manifest V3와 TypeScript 컴파일 결과를 Chrome에서 로드한다. | 미착수 |
| M1. 제어 흐름 | 조건 저장, 탭 연결, 시작/중지, 상태 표시를 연결한다. | 미착수 |
| M2. 모의 DOM 자동화 | DOM 추가 감지, 조건 판정, 단일 클릭, 결과 검증을 구현한다. | 미착수 |
| M3. 실제 페이지 어댑터 | 확인된 캐치테이블 DOM에 단일 예약 플로우를 연결한다. | 보류 |
| M4. 실사용 검증 | 실제 페이지에서 중복 클릭 없이 성능 기준을 측정한다. | 보류 |

## 이번 단계에서 한다

- Side Panel, Service Worker, Content Script의 최소 메시지 흐름
- 예약 조건과 감시 상태의 저장
- 모의 페이지 기반의 DOM 감시와 상태 전이 검증
- 실제 페이지 구조 확인 후 단일 예약 플로우 지원

## 이번 단계에서 하지 않는다

- 다중 사이트 또는 다중 플로우용 추상화
- 로그인, CAPTCHA, 결제 자동화
- 백엔드, 계정 동기화, 예약 이력 기능

## 전제 조건

- 실제 캐치테이블 예약 페이지의 예약 흐름을 사용자가 확인할 수 있다.
- M3 전에는 날짜, 인원, 시간 슬롯, 실패/성공 화면의 DOM 구조를 캡처한다.

## 마일스톤 상세

### M0. 확장 프로그램 골격

산출물:

- Manifest V3 구성
- TypeScript 컴파일 명령
- Side Panel, Service Worker, Content Script의 빈 진입점

완료 기준:

- Chrome 개발자 모드에서 확장 프로그램을 로드할 수 있다.
- 대상 탭에서 Content Script가 실행됐음을 확인할 수 있다.

### M1. 제어 흐름

산출물:

- 예약 조건 입력 폼
- `chrome.storage` 기반 설정 보존
- 감시 시작/중지와 상태 표시

완료 기준:

- 저장한 조건이 Side Panel을 다시 열어도 표시된다.
- 시작/중지 명령이 대상 탭 Content Script에 도달한다.

### M2. 모의 DOM 자동화

산출물:

- `MutationObserver` 기반 슬롯 감지
- 조건 판정과 한 번 클릭 보장
- `WATCHING`, `ACTING`, `VERIFYING`, `SUCCESS`, `RETRYING` 상태 전이

완료 기준:

- 조건과 일치하는 모의 슬롯이 추가되면 한 번만 클릭된다.
- 성공/실패/사용자 확인 필요 화면을 구분한다.
- 조건 일치 DOM 변경부터 클릭 호출까지의 시간을 기록한다.

### M3. 실제 페이지 어댑터

보류:

- 실제 페이지 DOM 구조 확인 전에는 구현하지 않는다.

완료 기준:

- 확인된 단일 예약 플로우에서 날짜, 인원, 시간 슬롯을 읽고 조건 일치 시 클릭한다.
- 식별하지 못한 화면에서는 자동화가 멈추고 이유를 표시한다.

### M4. 실사용 검증

완료 기준:

- 실제 페이지에서 같은 슬롯을 중복 클릭하지 않는다.
- 정상 동작, 슬롯 소진, 로그인 필요, 사용자 확인 필요 흐름을 수동으로 확인한다.
- 조건 일치부터 클릭까지의 로컬 p95가 50ms 이하인지 기록한다.

## Phase 완료 기준

- M0~M2가 자동 검증된다.
- M3~M4가 실제 단일 예약 플로우에서 검증된다.
- 비범위 자동화를 구현하지 않는다.
