# Phase 문서 규칙

`docs/phases/`는 단계별 실행 설계서다. 전체 순서는 [로드맵](../05-roadmap.md), 현재 위치는 [상태](../08-status.md), 작업자 기록은 [progress](../progress/README.md)에 둔다.

- 각 phase는 목적, 범위, 비범위, 마일스톤, 완료 기준을 가진다.
- 진행 로그는 phase 문서가 아니라 `progress/active/`에 남긴다.
- 상태값은 `미착수`, `진행 중`, `보완 중`, `완료`, `보류`를 사용한다.
- 완료 기준은 검증 가능한 문장으로 적는다.
