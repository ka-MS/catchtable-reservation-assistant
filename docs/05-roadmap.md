# 05. 로드맵

## 1단계 - 확장 프로그램 기반 자동화

목표: 사용자가 열린 캐치테이블 예약 탭에서 조건 감시를 시작하고, 조건과 일치하는 예약 UI가 나타났을 때 한 번만 즉시 클릭한 뒤 결과를 검증한다.

| 마일스톤 | 목표 | 상태 |
| --- | --- | --- |
| M0 | Manifest V3, TypeScript 컴파일, Side Panel 골격 | 미착수 |
| M1 | 조건 입력·저장과 감시 시작/중지 메시지 흐름 | 미착수 |
| M2 | 모의 예약 페이지에서 DOM 감시, 단일 클릭, 상태 전이 검증 | 미착수 |
| M3 | 실제 캐치테이블 페이지 DOM 확인과 단일 플로우 어댑터 구현 | 보류 |
| M4 | 실제 페이지 수동 검증과 성능 측정 | 보류 |

M3는 실제 페이지의 URL과 DOM 구조를 확인하기 전에는 시작하지 않는다. 각 마일스톤의 범위와 완료 기준은 [1단계 계획](phases/01-extension-foundation.md)에 있다.

## 이후 단계

1단계의 실사용 검증 결과가 나온 뒤 별도 설계한다. 현재는 예약 오픈 알림, 조건 템플릿, 추가 예약 플로우를 확정하지 않는다.
