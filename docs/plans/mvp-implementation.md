## 구현 순서 제약

- 각 항목은 실패 테스트 -> 최소 구현 -> 전체 테스트 순서로 진행한다.
- Site Adapter 코드는 fixture와 실측 문서가 먼저 존재해야 한다.
- 슬롯 이후 화면 코드는 작성하지 않는다.
- 실제 사이트 슬롯 클릭은 자동 검증하지 않는다.

## 완료 산출물

- `dist/`에서 로드 가능한 MV3 확장
- 독립적인 공식 문서 세트
- 핵심 단위 테스트, fixture 통합 테스트, 번들 회귀 테스트
- 상태·시계·동작 이벤트를 확인할 수 있는 Side Panel
- 미실측 영역과 2단계 취소 스나이핑 확장점
