# 후속 화면 복원력 분석

## 현재 구조

`PostSlotAdapter.inspect()`는 최신 visible dialog의 정확한 `aria-label`로 단계를 판별하고, `advance()`는 같은 정확 라벨의 dialog를 다시 찾아 행동한다. 최신 dialog 우선, 전환 중 disabled 대기, 메뉴 유형별 처리 등은 이미 지원한다.

## 확인된 취약점

- dialog의 `aria-label` 문구가 바뀌거나 제거되면 구조가 같아도 `unknown`이 된다.
- unknown 진단은 라벨 하나뿐이라 새 사례를 fixture로 재현하기 어렵다.
- inspection 이후 화면이 교체됐는지 행동 직전에 명시적으로 검증하지 않는다.
- 폼 프로모션은 실측 근거가 버튼 문구뿐이므로 정확 문구 의존이 남는다.

## 안전 경계

- 서버 시계, 날짜 토글, 슬롯 탐색·클릭은 변경하지 않는다.
- 유료 전용 예약금, 약관, 최종 예약은 자동 진행하지 않는다.
- 진단에는 URL 종류, dialog 제목, 버튼 문구와 상태, control 개수만 포함한다.
- 입력값, 전체 `innerHTML`, 이름·전화번호·결제정보는 수집하지 않는다.

## 목표

작은 접근성 라벨 변경은 독립적인 제목·control 구조로 계속 판별한다. 화면 증거가 모호하거나 inspection 이후 구조가 바뀌면 클릭하지 않고 진단 정보와 함께 사용자에게 인계한다.
