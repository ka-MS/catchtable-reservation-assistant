# 설정 히스토리·즐겨찾기 분석

## 목표

- 검증된 실행 설정을 최근 히스토리에 자동 저장한다.
- 사용자가 현재 설정을 즐겨찾기로 수동 저장한다.
- 저장 항목을 폼에 그대로 복원하고 단건·전체 삭제할 수 있게 한다.

## 기존 구조

- 설정과 실행 상태는 `chrome.storage.local`을 사용한다.
- Side Panel은 storage를 읽고 `storage.onChanged`로 갱신한다.
- Background는 실행 명령과 이벤트 저장을 소유하며 storage 쓰기 경합을 직렬화한다.
- `configFromFormValues()`는 구조 변환과 실행 시각 검증을 함께 수행한다.

## 결정이 필요한 위험

- `savedAt`을 ID로 사용하면 같은 밀리초 충돌 가능성이 있다.
- 식당 URL+날짜만 중복 기준으로 쓰면 같은 날 다른 인원·시간 설정을 잃는다.
- 지난 설정 복원은 허용하지만 실행 시에는 기존 시간 검증을 그대로 적용해야 한다.
- 설정 행의 `예약하기`나 삭제 이벤트가 폼 submit으로 전파되면 안 된다.
