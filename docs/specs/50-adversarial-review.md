# 50. 적대적 리뷰 및 수정

**상태:** active  
**실행일:** 2026-07-10

## 발견 및 수정

| 심각도 | 발견 | 수정 | 재검증 |
| --- | --- | --- | --- |
| 높음 | `YYYY-MM-DD`를 Catchtable의 `YYMMDD` URL 값으로 잘못 변환해 다른 날짜에서 감시할 수 있었음 | 연도 뒤 두 자리와 월일만 조합하도록 수정 | URL 날짜·인원 회귀 테스트 통과 |
| 높음 | 중지 명령이 감시 대상이 아닌 현재 활성 탭으로 전달될 수 있었음 | Service Worker가 기록한 감시 탭으로 중지 명령 전달 | TypeScript 검사 통과 |
| 중간 | 테이블 타입 라디오 클릭 직후 `다음`이 아직 비활성일 수 있었음 | 버튼이 활성화될 때까지 변이 관찰을 유지 | TypeScript 검사 통과 |
| 중간 | Side Panel 명령이 Content Script에도 전달될 수 있었음 | `PANEL_COMMAND` 외피를 도입해 Service Worker만 처리 | TypeScript 검사 통과 |
| 높음 | 감시 탭이 새로고침되면 새 Content Script에 감시 상태가 복구되지 않았음 | 저장된 감시 탭과 `CONTENT_READY` 신호를 대조해 같은 탭에만 `START` 재전달 | TypeScript 검사 통과 |
| 높음 | 확장을 이미 열린 탭에 설치하면 Content Script가 없어 시작 명령이 실패함 | `scripting` 권한으로 현재 감시 탭에만 주입 후 같은 명령을 재전달 | 구현 후 재검증 예정 |
| 치명적 | Manifest Content Script에 ES module `import`가 남아 Chrome이 스크립트를 실행할 수 없었음 | `esbuild`로 단일 IIFE 파일을 생성하고 산출물 import 부재를 자동 검사 | 7개 자동 테스트 통과. 실제 Chrome 재로드 검증 대기 |
| 중간 | 중지 요청 실패가 Side Panel에서 처리되지 않아 확장 오류 페이지에 `Uncaught`로 표시될 수 있었음 | 중지 요청도 UI 상태와 마지막 동작에 오류를 표시 | 구현 후 재검증 예정 |

## 잔여 위험

- 언패킹 로드는 사용자 확인으로 끝났지만, Side Panel의 실제 시작·중지 메시지 왕복은 아직 검증하지 못했다.
- Side Panel 연결은 실제 시작·중지 메시지 왕복으로 아직 확정할 수 없다.
- 슬롯 소진, 로그인 만료, CAPTCHA의 실제 DOM은 아직 확보되지 않았다. 이 화면들은 인식하지 못하면 자동 진행하지 않고 사용자 인계 또는 재감시로 제한한다.
- 테이블 타입 라디오의 실제 라벨 결합 방식은 단일 식당 근거만 있다. 실제 로드 검증에서 확인한다.
