# 슬롯 조상 가시성 적대적 리뷰

## 검토 결과

### Hot path 비용

실제 케아 슬롯 버튼 20개를 1,000회 스캔했다.

- 기존 필터: 스캔당 약 0.0075ms
- 새 조상 가시성 필터: 스캔당 약 0.2833ms
- 증가: 약 0.276ms/scan

100ms 토글 주기보다 충분히 작다. 조상 결과 캐시는 DOM 교체 시 stale 판정을 만들 수 있으므로 추가하지 않는다.

### 공용 가시성 계약의 한계

`isElementHidden()`은 `hidden`, `inert`, `aria-hidden`, `display:none`, `visibility:hidden`을 처리한다. `opacity:0`, 화면 밖 위치, 0 크기는 처리하지 않지만 RT-03은 기존 공용 계약을 SlotAdapter에 적용하는 작업이며 새로운 가시성 정의를 도입하는 작업이 아니다.

### 중복 제거 순서

가시성 필터가 분 단위 `Map` 삽입보다 먼저 실행된다. 따라서 숨겨진 복제본이 DOM에서 먼저 나타나도 가시 슬롯을 가리지 않는다.

### 클릭 안전성

`clickSlot()`은 후보의 과거 button 참조를 클릭하지 않고 `readSlots()`로 논리 키를 다시 찾는다. 이번 변경으로 재조회에도 동일한 조상 가시성 필터가 적용된다.

## 잔여 위험

- 실제 Catchtable에서 조상에만 숨김 속성이 있는 복제본은 아직 확보하지 못했다.
- 사이트가 공용 계약 밖의 방식으로 복제본을 숨기면 Tier 3 DOM drift 대응에서 새 실측 근거가 필요하다.

## 결론

차단 finding 없음. 변경 범위와 성능 비용이 제한적이며 RT-03을 완료 처리할 수 있다.
