# 01 신형 달력 DOM 호환 적대적 리뷰

상태: 완료

## 검토 결과

### 가상 월 혼입

Mobiscroll은 이전·현재·다음 월 테이블을 동시에 둔다. 판독기는 `aria-hidden`이 아니면서 `.mbsc-calendar-table-active`인 테이블이 정확히 하나일 때만 진행한다. 실페이지의 숨은 테이블 2개는 제외됐다.

### 부분 렌더와 활성 월 오판

활성 그리드가 6행, 행별 7셀, 총 42셀이 아니면 결과 전체를 거부한다. 표시 월 버튼이 둘 이상이어도 월을 추측하지 않고 거부한다. 두 조건 모두 회귀 테스트로 고정했다.

### 날짜 계산 불일치

셀에는 날짜 식별 속성이 없으므로 표시 월의 첫 요일에서 42개 날짜를 계산한다. 계산 결과는 각 셀의 선행 일 숫자 및 `.mbsc-calendar-day-outer`와 다시 대조한다. 사이트가 주 시작 요일이나 그리드 구조를 바꾸면 잘못 클릭하지 않고 판독 실패로 종료한다.

### 비활성·숨은 셀 클릭

`.mbsc-disabled` 또는 `aria-disabled=true`인 셀은 선택 후보에서 제외한다. 클릭 시 저장한 DOM 노드를 재사용하지 않고 논리 날짜로 다시 판독해 현재 연결된 셀만 한 번 클릭한다.

### 구형 회귀

구형 접근성 기반 판독을 우선 적용하고 Mobiscroll을 fallback으로 두었다. 기존 aria fixture와 새 Mobiscroll fixture가 함께 통과한다.

## 결론

현재 관측한 두 달력 변형을 지원하며, 모호하거나 부분 렌더된 화면에서는 추측 클릭하지 않는다. 잔여 위험은 Catchtable이 월 표기, 주 시작 요일, 활성 테이블 class를 동시에 변경하는 경우이며 이때 안전하게 인계되는 것이 의도한 동작이다.
