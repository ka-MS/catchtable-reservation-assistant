# 03 RT-07 복합 좌석·메뉴 실제 검증 적대적 리뷰

상태: 완료

## 발견 및 수정

1. **실측과 fixture의 진행 문구 불일치**: `확인` 단일 판별을 `다음`/`확인` 허용으로 수정했다.
2. **선택 후 화면 오인식**: 필수 메뉴 안내가 사라진 뒤 총 결제금액 요약과 선택 상태로 계속 판별하도록 수정했다.
3. **중복 진행 가능성**: 동일 버튼 노드에 대한 두 번째 클릭을 차단하고 테스트로 고정했다.
4. **결제 화면 전환 경쟁**: 프로모션이 늦게 나타나기 전의 `결제 방식 선택` 다이얼로그도 안전한 결제 단계로 판별하도록 수정했다.
5. **CTA 문구 접두사**: 정확히 일치 대신 실측 문구가 `이 방식으로 예약`으로 끝나는지 확인하고, 예약금 0원·자동결제 증거가 같은 조상에 있을 때만 클릭한다.

## 잔여 위험

- React가 진행 버튼 DOM을 교체하면서 이전 화면을 오래 유지하면 노드 단위 중복 방지가 약해질 수 있다. 최종 실런에서는 진행 이벤트가 정확히 한 번만 기록됐다.
- 실측은 야키토리묵 한 매장의 결합 화면이다. heading과 checkbox 계약이 크게 바뀌면 안전 인계된다.
- 최종 예약은 자동화 범위 밖이며 폼 도착 즉시 인계한다.
