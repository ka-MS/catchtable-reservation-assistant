# 02 결제 방식 자동 진행 적대적 리뷰

상태: 완료

## 검토 결과

- `이 방식으로 예약` 문구만 있는 유사 dialog는 자동 진행하지 않는다.
- 예약금 0원·자동결제 증거가 함께 있어야 신형 인터스티셜로 분류한다.
- 0원 방식이 없을 때 선택되지 않은 유료 방식은 클릭하지 않는다.
- aria-label이 없는 이미 선택된 활성 방식은 현재 선택을 바꾸지 않고 진행할 수 있다.
- disabled 0원 방식은 전환 중으로 보고 기다린다.
- 결제 자동 진행 off는 테이블·메뉴 등 선행 단계까지 막지 않는다.
- 구버전 저장 데이터의 필드 누락은 `true`로 정규화되어 기존 동작을 보존한다.
- 진단 데이터에는 dialog 전체 원문을 추가하지 않아 개인정보 노출 범위를 늘리지 않았다.
- `/ct/reservation/form`에서는 약관·최종 예약을 자동화하지 않는다.

## 잔여 위험

- 실제 비스트로 꼬꼬뜨 런에서는 신형 인터스티셜 전용 전략이 직접 기록되지 않았다. fixture와 유사 문구 거부 테스트로 계약을 고정했으며 다음 실관측 시 전략명을 교차 확인한다.
- 결제 방식 DOM이 radio가 아닌 새 control로 변경되면 안전하게 인계하며 fixture 추가가 필요하다.
