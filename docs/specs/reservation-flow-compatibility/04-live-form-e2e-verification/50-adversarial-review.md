# 04 실제 예약 폼 E2E 적대적 리뷰

상태: 완료

## 검토 결과

- 클릭 성공 메시지만으로 판단하지 않고 URL, 폼 예약 정보, active run, IndexedDB 이벤트를 교차 확인했다.
- 야키토리묵은 event count 31과 실제 저장 이벤트 31이 일치하고 seq 누락 및 dropped event가 없다.
- 두 식당 모두 최종 상태가 `HANDED_OFF`이며 최종 예약 버튼은 조작하지 않았다.

## 잔여 위험

- 실측은 현재 Chrome 프로필과 2026-07-14 DOM에 한정된다.
- 로그인 여부에 따라 폼 내부 구성은 달라질 수 있으나 폼 URL 인계 경계에는 영향이 없다.
- 예약금·결제 정책이 바뀌면 강한 증거가 없는 화면은 자동 진행하지 않고 인계한다.
