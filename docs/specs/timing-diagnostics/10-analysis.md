# 정밀 타이밍 로그·고급 설정 분석

## 문제

- 기존 `시간 선택 완료 +Nms`는 목표 날짜 클릭, 슬롯 DOM 반영, 슬롯 감지와 클릭 시간을 모두 합친 결과다.
- 사전 시작값별 차이가 스케줄 오차인지 Catchtable 렌더 지연인지 구분되지 않는다.
- 고급 설정 이름만으로는 사전 시작, 토글 간격, 시계 표본의 역할을 알기 어렵다.
- 사전 시작 input은 100ms step이라 50ms 단위 실험이 불편하다.

## 필요한 관측점

1. 인접 날짜 실제 클릭 시각
2. 목표 날짜 실제 클릭 시각과 계획 대비 스케줄 오차
3. 조건 일치 슬롯 최초 감지 시각
4. 시간 슬롯 클릭 완료 시각

모든 관측 시각은 보정된 서버 시각과 예약 오픈 대비 signed ms를 함께 기록한다.
