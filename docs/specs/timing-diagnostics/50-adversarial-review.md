# 정밀 타이밍 로그·고급 설정 적대적 리뷰

## 검토 항목

- 로그 전송이 정각 토글이나 슬롯 클릭을 지연시키는가
- 이전 토글 주기의 클릭 시각이 최종 슬롯 감지에 잘못 결합되는가
- 계획 오차와 오픈 대비 지연을 혼동하는가
- dry-run과 실제 실행의 타이밍 데이터가 달라지는가
- 기존 저장 설정이 50ms 검증과 충돌하는가

## 리뷰 결과

1. **높음, 예방:** 날짜 클릭마다 이벤트를 전송하면 핫 루프에 IPC가 추가된다. 클릭 시각은 메모리에만 기록하고 기존 슬롯 감지 이벤트에 최종 주기를 첨부했다.
2. **중간, 수정 완료:** 기존 슬롯 선택은 이벤트 생성 시각을 암묵적으로 사용했다. 클릭 직후 서버 시각을 한 번 캡처해 `timingServerAtMs`와 `openDeltaMs`를 같은 값에서 계산한다.
3. **낮음, 수정 완료:** 한 줄 상세 문자열로는 단계 구분이 어려웠다. 인접·목표·감지를 줄 단위로 분리하고 날짜 클릭에만 계획 오차를 표시한다.

기존 100ms 단위 설정은 모두 50ms 배수라 그대로 유효하다. 치명적·높음 미해결 문제는 없다.
