# 정밀 타이밍 로그·고급 설정 구현

## 구현 결과

- 오케스트레이터가 매 토글의 마지막 인접·목표 클릭 시각과 계획 시각을 메모리에 보존한다.
- 슬롯 감지 상태 이벤트에 최종 클릭 두 개와 감지 시각을 함께 기록한다.
- 슬롯 선택 상태 이벤트에 명시적인 선택 시각과 오픈 대비 지연을 기록한다.
- Side Panel은 인접·목표·감지 시각을 줄 단위로 표시한다.
- 고급 설정 세 항목에 한 줄 설명을 추가했다.
- 사전 시작 input step과 설정 검증을 50ms 단위로 변경했다.

로그 계측 때문에 정밀 루프에서 `chrome.runtime.sendMessage` 호출이 늘어나지 않도록 날짜 클릭 자체는 이벤트로 즉시 전송하지 않는다.
