## 남은 실제 검증

1. Chrome 개발자 모드에서 `dist/`를 언패킹 확장으로 로드한다. - 사용자 수행 완료 확인
2. 실제 `kea` 예약 페이지에서 Side Panel이 열리고 설정이 저장되는지 확인한다.
3. 결제·최종 예약을 실행하지 않는 범위에서 시작·중지와 사용자 인계 상태를 확인한다.

이 항목이 끝나기 전에는 이 문서를 `passed`로 바꾸지 않는다.

## 환경 제약

2026-07-10에 자동으로 `chrome://extensions`를 열어 언패킹 로드를 시도했으나, 이 브라우저 제어 환경의 보안 정책이 Chrome 내부 설정 URL 접근을 차단했다. 이는 확장 코드 오류가 아니다. 사용자가 Chrome UI에서 개발자 모드와 언패킹 로드를 한 번 수행한 뒤에는 일반 Catchtable 페이지에서의 기능 검증을 계속할 수 있다.

## 실제 페이지 관찰

사용자가 `dist/` 언패킹 로드를 완료했다고 확인했다. 이어서 로그인된 `kea` 예약 페이지를 읽기 전용으로 확인했다. 만료된 예약 찜의 결제 전 화면에는 약관 체크박스와 `자동결제로 예약하기` 최종 버튼이 표시됐다. 이 UI는 설계의 `PAUSED_USER` 판별과 일치하며, 최종 버튼·약관은 클릭하지 않았다.

Side Panel의 시작·중지 메시지 왕복은 Chrome UI 영역이 자동화 API에 노출되지 않아 아직 실제로 검증하지 못했다.
