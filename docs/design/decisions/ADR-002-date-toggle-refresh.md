# ADR-002: 날짜 토글로 슬롯 갱신

**상태:** 채택  
**일자:** 2026-07-10

## 결정

슬롯 갱신은 인접 가용 날짜를 클릭한 뒤 목표 날짜를 클릭하는 UI 토글로 수행한다. 정밀 구간은 목표 날짜 클릭을 오픈 시각에 위상 고정하고 `T-450ms`, `T-300ms`, `T-150ms`, `T`, `T+150ms`에 배치한다. 각 인접 날짜 클릭은 목표 날짜 클릭 40ms 전에 수행한다.

## 근거

다른 날짜 클릭은 사이트가 슬롯을 다시 조회하지만 같은 날짜 재클릭은 조회하지 않는다. 직접 API 호출은 암호화된 요청을 재현해야 하므로 사용하지 않는다.

## 영향

실행 전에 목표 날짜와 인접 가용 날짜가 모두 필요하다. 인접 날짜가 없으면 자동화하지 않고 사용자에게 인계한다. 오픈 후 2초까지는 최대 150ms 간격을 유지하고 이후에는 부하를 줄이기 위해 점진적으로 간격을 늘린다.
