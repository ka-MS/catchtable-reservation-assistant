# ADR-003: 서버 Date 헤더 기반 시계 보정

**상태:** 채택  
**일자:** 2026-07-10

## 결정

같은 오리진 매장 URL의 HEAD 응답 Date 헤더를 여러 번 측정하고 RTT와 중앙값을 이용해 서버 오프셋을 추정한다.

## 근거

로컬 시계 오차를 줄일 수 있고 외부 시간 서비스가 필요 없다. 캐시된 `robots.txt`와 CORS로 노출되지 않는 API Date 헤더는 사용하지 않는다.

## 영향

시계 측정 실패는 경고와 함께 로컬 시계 fallback으로 명시한다. Clock은 테스트에서 주입 가능해야 한다.
