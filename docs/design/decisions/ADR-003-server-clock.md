# ADR-003: 서버 Date 헤더 기반 시계 보정

**상태:** 채택  
**일자:** 2026-07-10

## 결정

같은 오리진 매장 URL의 HEAD 응답 Date 헤더를 기본 9회 측정한다. 연속 응답 사이에서 HTTP Date의 초 값이 바뀌면 두 요청 중간 시각으로 서버 초 경계를 추정하고, 경계가 관찰되지 않을 때만 최소 RTT 표본군의 중앙 오프셋을 사용한다. 장시간 대기 실행은 오픈 직전에 한 번 더 측정한다.

## 근거

로컬 시계 오차를 줄일 수 있고 외부 시간 서비스가 필요 없다. HTTP Date의 1초 해상도 때문에 단일 표본의 밀리초 부분을 서버 시각으로 간주할 수 없으므로, 초 경계를 직접 관찰해 위상 오차를 줄인다. 캐시된 `robots.txt`와 CORS로 노출되지 않는 API Date 헤더는 사용하지 않는다.

## 영향

시계 측정 결과는 `boundary`, `median`, `local` 방법과 추정 정밀도를 기록한다. 오픈 직전 재측정이 실패하면 초기 오프셋을 유지한다. Clock은 테스트에서 주입 가능해야 한다.
