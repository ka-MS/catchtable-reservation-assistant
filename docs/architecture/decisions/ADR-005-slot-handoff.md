# ADR-005: 슬롯 클릭 직후 사용자 인계

**상태:** 대체됨
**일자:** 2026-07-10
**대체일:** 2026-07-23 정책 전환, 2026-07-27 구현 완료
**대체 문서:** `docs/specs/automation-boundary.md`,
`docs/specs/catchpay-reservation-completion/`

이 ADR은 초기 MVP의 안전 경계를 기록한 역사 문서다. 현재 실행은
후속 선택 설정과 예약 완주 opt-in에 따라 슬롯 이후 화면과 예약 폼을
처리한다.

## 결정

MVP 자동화의 마지막 DOM 동작은 목표 슬롯 클릭이다. 클릭 직후 어떤 화면도 해석하거나 조작하지 않고 `HANDED_OFF`로 종료한다.

## 근거

슬롯 이후 화면은 공식 실측 범위가 아니며 잘못된 후속 클릭은 예약 조건이나 결제에 영향을 줄 수 있다.

## 영향

테이블 타입, 예약금, 약관, 결제, 최종 확정은 MVP 코드와 테스트에서 제외한다.
