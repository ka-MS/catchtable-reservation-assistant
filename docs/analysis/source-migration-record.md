# 초기 분석 자료 이관 기록

2026-07-10에 별도 실험 저장소에서 수집된 다음 자료를 검토하여 현재 저장소의 공식 문서로 재작성했다.

- DINING 달력 날짜 셀의 ARIA 구조
- 시간 슬롯의 `data-busy`, `aria-hidden`, 캐러셀 복제 구조
- 날짜 토글에 따른 사이트 자체 슬롯 재조회
- 같은 오리진 매장 문서의 HTTP Date 헤더를 이용한 시계 보정
- 기존 구현의 추측 셀렉터, 이중 주입, 영구 pause, 시간대 오류 분석
- MV3 on-demand 주입과 슬롯 클릭 직후 사용자 인계 결정

이 문서는 출처 이력만 기록한다. 개발·테스트에 필요한 내용은 모두 현재 저장소의 `docs/`에 포함되어 있으며 외부 저장소를 읽을 필요가 없다.
