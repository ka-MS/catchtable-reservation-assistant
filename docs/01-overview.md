# 01. 개요

## 목표

사용자가 로그인한 캐치테이블 Chrome 탭에서 원하는 예약 조건을 감시하고, 조건과 일치하는 예약 가능 UI가 나타나면 즉시 다음 예약 단계를 클릭하는 개인용 확장 프로그램을 만든다.

## 해결하려는 문제

- 인기 식당의 예약 가능 시간은 짧은 시간 안에 사라진다.
- 사용자는 날짜, 인원, 시간 조건을 반복 선택하며 화면을 계속 확인해야 한다.
- 빈자리가 나도 예약 조건과 취소 규정을 판단하는 시간이 예약 성공 가능성을 낮춘다.

## 1단계 범위

- Chrome Manifest V3 확장 프로그램
- Side Panel에서 예약 조건 입력, 시작/중지, 상태 확인
- Content Script의 DOM 감시와 조건 일치 슬롯 클릭
- 클릭 결과 검증과 지속 재시도 상태 관리
- 로그인, CAPTCHA, 수수료/결제 확인 단계에서 사용자에게 제어권 반환

## 비범위

- 계정 로그인, 비밀번호·쿠키·결제정보 저장
- CAPTCHA 또는 접속 대기열 우회
- 비공개 API 호출과 다수 계정/다수 탭 자동화
- 결제 또는 취소 수수료 동의의 자동 확정
- 서버, 모바일 앱, React 기반 UI

## 사용자

캐치테이블 계정으로 직접 예약하며, 빠른 조건 감시와 정상 UI 흐름 보조가 필요한 개인 사용자.

## 이후 단계

1단계가 실제 예약 페이지에서 안정적으로 동작한 뒤에만 다음을 검토한다.

- 예약 이력과 조건 템플릿
- 예약 오픈 시각 알림
- 지원 식당/예약 플로우 확대
