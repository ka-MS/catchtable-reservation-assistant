# Evidence

실제 Catchtable 실행에서 수집한 원본 증거를 보관하는 패키지다. 분석·설계 문서는 원본을 복사하지 않고 이 경로를 링크한다.

## 패키지

| 패키지 | 내용 |
|---|---|
| [live-runs](live-runs/README.md) | 날짜·실행별 Trace CSV, 진단 bundle, 보조 이미지 |

## 원칙

1. 원본은 실행별 단일 디렉터리에만 둔다.
2. 원본 증거와 해석을 분리한다. 분석 결론은 `docs/analysis` 또는 관련 `docs/specs`에 기록한다.
3. 동일 실행을 여러 스펙에서 사용할 때 복제하지 않고 링크한다.
4. 재현 가능한 최소 DOM만 정제해 `tests/fixtures`로 승격한다.
5. 개인정보, 결제정보, 인증정보, 네트워크 원문 body는 저장하지 않는다.
6. 대용량 영상은 저장소 밖에 두고 분석 문서에 위치와 관찰 결과만 기록한다.

Raw evidence는 그 자체로 제품 계약이 아니다. 관련 분석 문서에서 범위와 한계를 명시한 뒤 공식 근거로 사용한다.
