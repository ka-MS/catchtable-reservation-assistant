# 2026-07-11 카운트다운 다듬기·감시 종료 자동값 복구 작업 로그

## 문제

1. 저장 설정을 한 번 불러오면 `stopAtDirty`가 true로 영구 저장되어, 이후 오픈 일시를 바꿔도 감시 종료 시각이 +10분으로 따라가지 않았다.
2. 남은 시간 1분 미만 강조가 글자 크기를 키워 배너 높이가 변했다.
3. 배너가 헤더 밖에서 별도로 sticky여서 스크롤 시 위치가 어색했다.

## 수정

1. 저장된 dirty 플래그(`draftStopAtDirty`)를 제거하고, "감시 종료 시각이 오픈+10분 기본값과 다른가"를 `stopAtIsCustom`(form-model 순수 함수)으로 그때그때 판정한다. 초안 복원·설정 복원·저장 설정 불러오기 모두 같은 규칙을 쓰므로 기본값이면 자동 갱신이 복구되고, 커스텀 감시 시각은 유지된다.
2. 긴급 강조를 색상 변화만으로 바꿔 배너 크기를 고정했다. 단계 모드 글자 크기도 동일하게 맞췄다.
3. 배너를 헤더 내부로 옮겨 헤더와 한 몸으로 고정했다. `display: flex`가 `hidden` 속성을 덮어쓰던 잠재 버그도 `[hidden]` 규칙으로 수정했다.

## 검증

- `stopAtIsCustom` 실패 테스트를 먼저 작성해 RED 확인 후 구현했다.
- 빌드된 Side Panel을 로컬 서버로 렌더링해 모든 모드·강조 조합에서 배너 높이 39px, 글자 18px 고정과 hidden 시 `display: none`, 헤더 내 포함·sticky를 계측으로 확인했다.
- `npm run check` 전체 통과 (110 tests + dist + independence).
