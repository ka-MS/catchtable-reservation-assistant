# 2026-07-11 감시 종료 dirty 플래그 완전 제거 작업 로그

## 배경

감시 종료 시각의 "직접 수정 보호" 플래그(`stopAtDirty`)는 사용자가 정한 감시 시간을 오픈 일시 변경이 덮어쓰지 않게 하려는 장치였다. 그러나 영구 저장 오판, 값 비교 오판 등 연쇄 버그의 원인이 됐고, 보호하려는 시나리오(감시 시각 수정 후 오픈 일시 재수정) 자체가 드물어 복잡도가 실익을 초과한다고 판단해 완전히 제거했다.

## 수정

- `stopAtDirty` 플래그와 관련 분기를 모두 제거했다.
- 규칙 단일화: 오픈 일시를 변경하면 감시 종료 시각은 항상 오픈+10분으로 재설정된다. 직접 수정한 감시 종료 값은 다음 오픈 일시 변경 전까지만 유지된다.
- README와 UI 요구사항의 기존 "직접 수정 후 덮어쓰지 않음" 규칙을 새 규칙으로 교체했다.

## 검증

- `npm run check` 전체 통과.
