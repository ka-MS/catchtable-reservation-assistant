## 가설 수정

worklog 08의 "응답 서버 풀 간 시계 편차" 가설을 재검토했다. 9샘플 데이터의 각 Date-초 그룹 내부 오프셋이 샘플 간격(~125~150ms)마다 ~200~240ms씩 선형 감소하는 정상 톱니파를 보였다 — 이는 단일 서버 시계에서 로컬 시간이 한 초 구간 안을 지나며 나타나는 정상 현상이지, 여러 풀이 섞인 신호가 아니다. 5샘플 실런의 "d2000 순간 점프"는 성긴 표본 간격과 지연 변동이 겹쳐 톱니파가 앨리어싱된 결과였을 가능성이 높다.

풀 편차 자체를 완전히 반증한 것은 아니다(다른 시각·다른 CDN 라우팅에서 재현될 수 있음). 다만 **표본 9개를 쓰면 실용적으로 문제가 재현되지 않으므로**, 합의 검증 로직(worklog 09)은 유지하되 — 편차가 없을 때는 그냥 정상적인 진짜 경계를 찾아낼 뿐이라 부작용이 없다.
