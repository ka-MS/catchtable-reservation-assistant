## 현재 상태

실행 기록에 최종 인접 날짜 클릭, 목표 날짜 클릭, 슬롯 감지와 슬롯 선택의 서버 시각을 분리했다. 날짜 클릭은 오픈 대비 지연과 계획 대비 오차를 함께 표시하며, 정밀 루프에서는 메모리 계측만 수행해 추가 로그 IPC를 만들지 않는다. 고급 설정에는 한 줄 도움말이 있고 사전 시작은 50ms 단위로 입력·검증한다.

## 다음 작업

1. `chrome://extensions`에서 확장 카드를 새로고침한다.
2. 동일 조건에서 사전 시작값을 바꾸며 인접·목표·감지·선택 로그를 비교한다.
3. 목표 날짜의 `계획 ±Nms`와 슬롯 선택의 `오픈 ±Nms`를 구분해 확인한다.
4. 사전 시작 50ms 단위 입력과 고급 설정 도움말을 확인한다.
