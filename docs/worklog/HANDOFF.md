## 현재 상태

실행 중 발견된 후속 단계 오판을 수정했다. 하오카오스탠 실측으로 dialog 전환 중 선택지가 일괄 `aria-disabled`되는 ~130ms 윈도우를 확인했고, 활성 선택지 0개를 `blocked`가 아닌 `waiting`으로 재시도하도록 바꿨다. 유료 `예약금 안내` dialog도 실측해 `확인` 클릭으로 진행한다(결제 실행 아님). 후속 자동 진행은 기본 꺼짐이며, 끄면 슬롯 선택까지만 수행한다.

## 다음 작업

1. `chrome://extensions`에서 확장 카드를 새로고침한다.
2. 테이블 타입 뒤 전환 구간에서 인계 없이 다음 단계로 진행되는지 실제 실행으로 검증한다.
3. 예약금 안내가 있는 식당에서 `확인` 진행 후 예약 폼 인계를 확인한다.
