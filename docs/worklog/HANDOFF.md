## 현재 상태

Side Panel 헤더 아래에 오픈 카운트다운 배너를 추가했다. 오픈 일시가 입력되면 항상 표시되고, 실행 중 측정된 최신 시계 오프셋이 있으면 서버 시계 기준, 없으면 로컬 시계 기준을 라벨로 구분한다. 1분 미만은 색상으로만 강조되고(크기 고정), 오픈 후 실행 중이면 현재 단계 배지, 미실행이면 오픈 경과 시간으로 전환된다. 배너는 헤더 내부에서 헤더와 함께 고정된다. 감시 종료 시각은 dirty 보호 없이 오픈 일시 변경 시 항상 +10분으로 재설정된다. 설정 히스토리·즐겨찾기(직전 작업)는 사용자 확인까지 완료됐다.

## 다음 작업

1. `chrome://extensions`에서 확장 카드를 새로고침한다.
2. 오픈 일시 입력 직후(로컬 기준)와 실행 중(서버 기준) 카운트다운 표시를 확인한다.
3. 오픈 시각 경과 시 단계 배지 전환과 1분 미만 색상 강조를 확인한다.
4. 오픈 일시를 바꿀 때마다 감시 종료가 +10분으로 재설정되는지 확인한다.
