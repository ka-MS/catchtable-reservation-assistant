# 2026-07-11 오픈 카운트다운 배너 작업 로그

## 요구

예약 오픈까지 남은 시간을 서버 시간 기준으로 Side Panel 헤더 아래에 상시 표시한다.

## 구현

- `src/sidepanel/countdown.ts` 순수 모델: 오픈 일시가 있으면 항상 표시하고, 최신 시계 보정 오프셋(`clockOffsetMs` metric 이벤트)이 있으면 서버 시계 기준, 없으면 로컬 시계 기준을 라벨로 구분한다.
- 표시 규칙: 남은 시간 `오픈까지 H:MM:SS`(24시간 이상은 `N일` 접두, 1분 미만 강조), 오픈 후 실행 중이면 현재 단계 배지, 미실행이면 `오픈 경과 +H:MM:SS`.
- Side Panel은 500ms 간격과 오픈 일시 변경·실행 상태 갱신 시 배너를 다시 그린다. 새 측정은 하지 않고 기존 이벤트의 오프셋만 재사용한다.
