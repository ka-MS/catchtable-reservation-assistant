# 2026-07-11 예약 폼 도착 처리 개선 작업 로그

## 요구

1. 예약 폼 도착 직후 비결정적으로 덮는 홍보 안내 창(`확인했어요` 버튼)이 있으면 닫고 인계한다.
2. 예약 폼 도착 인계 이벤트에도 시간 슬롯 클릭과 같은 형식으로 서버 시각과 오픈 대비 지연을 표시한다.

## 구현

1. adapter `inspect()`가 폼 URL에서 `확인했어요` 버튼을 발견하면 `form_notice`를 반환하고, `advance()`가 해당 버튼을 1회 클릭한다. 닫힌 뒤 다음 사이클에서 `form`으로 인계된다. 홍보 창은 화면 증거만 있으므로 버튼 텍스트 정확 일치로만 판정한다. 결제·응모 조작이 아니다.
2. orchestrator가 폼 도착 `HANDED_OFF` 전이에 `openDeltaMs`를 첨부한다. 기존 이벤트 포맷터가 `· 서버 HH:MM:SS.mmm (+Nms)`를 자동 표시한다.

## 검증

- 실패 테스트 2개(홍보 창 닫기, 폼 인계 이벤트의 openDeltaMs)를 먼저 작성해 RED 확인 후 구현했다.
- `npm run check` 전체 통과 (63 tests + dist + independence).
