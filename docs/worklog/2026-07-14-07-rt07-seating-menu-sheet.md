# 2026-07-14 RT-07 seating menu sheet

## 목표

야키토리묵에서 관측된 좌석·필수 메뉴 결합 바텀시트를 기존 안전 경계 안에서 지원한다.

## 수행

1. 저장 trace와 live DOM을 대조하고 `role=presentation` 결합 화면을 재현했다.
2. 별도 `seating_menu` kind, 판별 증거, 좌석 대응 정책을 설계했다.
3. live 구조 fixture와 실패 테스트를 먼저 추가했다.
4. 카드 단위 좌석·메뉴 선택과 `확인` 진행을 구현했다.
5. 적대적 리뷰에서 일반 필수 메뉴 오탐 위험을 찾아 카드 heading의 좌석 문구 조건을 추가했다.
6. 전체 자동 게이트와 live 비최종 전환을 검증했다.

## 결과

- `테이블`과 `카운터` 결합 카드를 설정에 따라 선택한다.
- 없는 좌석이나 일반 메뉴 presentation은 클릭하지 않는다.
- 예약 폼 도착까지만 확인하고 약관·결제·최종 예약은 건드리지 않는다.
- 테스트 245/245, dist·독립성 검증 통과

## 제한

배포 확장의 전체 자동 live run은 기존 날짜 준비 판정에서 먼저 인계됐다. 자세한 증거는 `docs/specs/seating-menu-sheet/40-verification.md`에 기록했다.
