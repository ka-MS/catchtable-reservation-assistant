# 2026-07-12 사이드패널 UX 개선

## 배경

무인 스케줄러 첫 실사용 피드백: 하단 액션바가 '최근 설정'을 가림, 버튼이 조잡함, 완료 작업이 계속 쌓여 보임, 폼에서 실행 로그가 안 보임, 화면 전환이 발견하기 어려움. 사용자가 목업(`catchtable_ui_improvement_mockup.html`)을 제공했다.

## 수행 (표현 계층만 변경)

- 헤더에 세그먼티드 내비(작업/예약 설정/실행 로그)를 추가하고 하단 "목록으로" 버튼을 제거했다. `aria-current`로 현재 화면을 표시한다.
- 홈 전폭 버튼을 타이틀 행의 컴팩트 `+ 새 예약`으로 바꿨다.
- 하단 액션바를 폼 화면 전용으로 한정하고 `예약 저장 | 지금 시작` 2버튼을 한 줄(2열 grid)로 배치했다. 본문 하단 여백을 `body[data-view]`로 제어해 다른 화면에서 여백 낭비와 가림을 없앴다.
- 홈 목록은 활성(예정·실행 중) 작업만 기본 노출하고, 완료·놓침 작업은 "완료된 작업 N개 보기 ▾" 토글로 접었다.
- 폼 화면 하단에 미니 로그(최근 3건 + 전체 보기)를 추가했다. 기존 이벤트 데이터를 읽기만 한다.
- 실행 중지 버튼을 실행 화면 본문(runtime-tools)으로 옮겼다.
- 전역 오류 문구(`#form-error`)를 헤더로 옮겨 모든 화면에서 보이게 했다.
- 뷰 모델을 순수 함수로 분리했다: `jobListModel`(활성/완료 분리·정렬·라벨), `miniLogModel`(최신 3건·빈 상태 문구).

background 로직과 메시지 계약(SCHEDULE_JOB/DELETE_JOB/PANEL_START/PANEL_STOP)은 변경하지 않았다.

## 검증

- 단위·fixture 테스트 150개 통과 (신규 4개: job-list-model)
- 타입 검사, `dist` 검증, 모듈 독립성 검증, `git diff --check` 통과
- 세션 내 브라우저 프리뷰는 WSL↔Windows localhost 포워딩·스크린샷 서브시스템 문제로 실측 실패. 마크업 구조는 정독으로 검증했고 실제 시각 확인은 아래 수동 항목으로 남긴다.

## 사용자 확인

1. `chrome://extensions`에서 확장을 새로고침한다.
2. 폼 화면에서 '최근 설정'을 펼쳐도 액션바에 가리지 않는지 확인한다.
3. 내비로 세 화면 전환이 되고 active 표시가 정확한지 확인한다.
4. 홈에서 완료 작업이 기본 접힘이고 토글로 펼쳐지는지 확인한다.
5. 폼 미니 로그에 최근 실행 기록이 보이고 "전체 보기"가 실행 화면으로 이동하는지 확인한다.
6. 실행 화면에서 중지 버튼이 동작하는지 확인한다.
