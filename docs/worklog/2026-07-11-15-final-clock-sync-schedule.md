# 2026-07-11 최종 시계 재보정 분리

## 수행

- 최종 서버 시계 재보정 시점을 사전 시작 설정에서 분리했다.
- 일반 설정에서는 서버 시각 기준 오픈 5초 전에 재보정을 시작한다.
- 사전 시작이 3초를 넘으면 토글을 늦추지 않도록 재보정을 더 앞당긴다.
- 재보정 실패 시 기존 단조 서버 앵커를 유지한다.

- 사전 시작 0·200·3000·4000·10000ms 경계 테스트 추가

- 전체 단위·fixture 테스트 118개 통과
- 타입, `dist`, 모듈 독립성, diff 검사 통과

## 사용자 확인

- 확장 새로고침 후 최종 보정 로그가 오픈 약 2~3초 전에 완료되는지 확인한다.
- 사전 시작 값을 바꿔도 일반 범위에서는 최종 보정 시작점이 변하지 않는지 확인한다.
